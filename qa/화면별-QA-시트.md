### Flow A — 음역 탐색

홈 → 안내 → 낮은 구간 → 중간 구간 → 높은 구간 → 분석 → 보이스 리포트.

- 판정: PASS
- 저장: `measurement`, `voiceProfile`
- 확인: 음역 이름 직접 입력 없음, 전체·안정 구간 분리

### Flow B — 곡·파트 참여

곡 탐색 → 곡·파트 상세 → 열린 파트 → 궁합 → 참여 조건 → 프로젝트룸.

- 확인: 사람 이름보다 곡·파트·키·목표일 우선

## 5. 시각 자기검토

- 음악 앱의 흔한 보라·핑크·네온을 사용하지 않았다.
- 모든 콘텐츠를 동일한 둥근 카드로 자르지 않았다.
- 카세트만 강한 기억점으로 두고 측정·곡·조건 화면은 조용하게 유지했다.
- 손글씨는 J카드 크레딧에만 사용했고 일반 UI에는 사용하지 않았다.
- 영문 대문자 Eyebrow와 장식용 번호의 반복을 피했다.
- 음색 이미지는 얼굴을 대체하지만 파트 판단 정보보다 앞서지 않는다.
- 카세트 사진은 맥락 이미지이며 실제 진행 상태는 별도 DOM/CSS/SVG 컴포넌트가 담당한다.
