# 이음 — 디자인 명세

**이 문서는 뒤늦게 만든 것입니다.** 화면을 만들 때 참고한 md 가 따로 있었던 게 아니라,
토큰을 각 HTML 에 직접 박아 쓰고 있었습니다. 그래서 여기 적힌 값은
실제로 쓰인 `카세트J카드.html` · `매칭스와이프.html` · `곡과가사.html` 에서 뽑았습니다.
대비 수치는 계산해서 넣었습니다.

먼저 **아래 12번의 어긋난 것 두 개**를 읽고 시작하세요.

---

## 1. 분위기

사용자가 `together` 라는 레터링을 보고 "내 눈에는 가장 비슷한 느낌"이라고 고른 데서 나왔습니다.

- 획이 이어진다 — 끊기지 않고 흐른다
- 굵기가 일정하다 — 장식 없는 한 획
- 자간이 넓다 — 급하지 않다
- 얼굴이 없다 — 음색과 손글씨가 그 사람을 대신한다
- 종이와 테이프의 물성 — 화면이 아니라 물건처럼

**하나의 완성품 = 카세트 테이프.** 협업 과정 = J카드를 채워 가는 것.
두 사람은 **서로 다른 손글씨**로 남습니다.

## 4. 글자

```css
본문  "Pretendard", "Apple SD Gothic Neo", "Malgun Gothic", sans-serif
손글씨 "Nanum Pen Script"  (사람 1)
       "Gaegu"             (사람 2)
```

손글씨 둘은 **서로 달라야 합니다.** 같은 폰트를 두 사람에게 쓰면 기획이 무너집니다.
`카세트J카드.html` 검사에 이 항목이 들어 있습니다.

| 쓰임 | 크기 | 행간 | 굵기 | 그 밖 |
|---|---|---|---|---|
| `h1` | 28px | 1.14 | 600 | 자간 −.01em |
| `.eyebrow` | 11px | — | — | 자간 .18em, 대문자 |
| `h2` | 12px | — | 600 | 자간 .14em, 대문자, `--ink-3` |
| `.lead` | 15px | 1.5 | — | `--ink-2` |
| 본문 | 16px | 1.5 | — | |
| `.tiny` | 11px | 1.7 | — | `--ink-3` |
| 버튼 | 13px | — | — | `.mini` 는 12px |
| `.chip` | 11px | — | — | |
| 큰 숫자 | 40px | 1 | 600 | 자간 −.03em, `tabular-nums` |
| 손글씨 이름 | 34px | 1 | — | 자간 .02em |
| 노래방 가사 | 26px | 1.35 | — | 자간 .02em, 가운데 |

숫자를 띄울 때는 **반드시** `font-variant-numeric: tabular-nums`. 안 그러면 값이 바뀔 때 폭이 흔들립니다.

## 5. 레이아웃

```css
main { max-width: 420px; margin: 0 auto; padding: 48px 16px 64px; }
html, body { overflow-x: hidden; }
```

**모바일 폭이 먼저입니다.** 375px 에서 가로로 넘치면 안 됩니다.
`min-width` 를 쓰지 마세요 — 처음에 J카드에 `min-width:554px` 을 박아서 폰에서 잘렸습니다.

넘침 검사를 화면마다 넣어 두었습니다.

```js
document.documentElement.scrollWidth <= window.innerWidth + 1
```

.why li:before { content:''; position:absolute; left:2px; top:12px;
                 width:5px; height:5px; border-radius:50%; background: var(--ink-3); }

### 음역 막대 — 얼굴을 대신하는 자리

C2(36)~C6(84) 눈금 위에 두 줄을 겹칩니다.
연한 막대 = 전체 음역(`lo`~`hi`), 진한 막대 = 편한 구간(`lo90`~`hi90`).
아래에 곡의 파트를 점선으로 놓습니다. 높이 13px, 사이 7px.

**맨 오른쪽 눈금 글자는 `text-anchor="end"` 로 선 왼쪽에 붙이세요.** 안 그러면 잘립니다.

### 노래방 가사

현재 줄 26px `--ink`, 다음 줄 19px `#C0B8AC`.
지나간 글자만 파트 색으로 켭니다.

**줄이 끝나도 다음 줄이 실제로 시작할 때까지 앞 줄을 남기세요.**
끝나자마자 지우면 쉬는 동안 화면이 빕니다.

## 11. 검사

화면마다 `window.__T()` 를 두고 페이지를 열 때 자동으로 돌립니다.
표에 항목·결과·판정이 채워집니다.

**전환 효과를 끄고 재세요.** 창이 화면에 안 그려지면 전환이 멈춰 있어서,
켜 둔 채로 `getComputedStyle` 을 읽으면 환경을 탑니다.

```css
body.notrans * { transition: none !important; animation: none !important; }
```

불투명도 대신 **위치**(`getBoundingClientRect`)로 확인하면 더 단단합니다.

## 12. 어긋난 것 — 정해 주셔야 합니다

### ① 사람 1 의 색이 화면마다 다릅니다

| 화면 | 사람 1 / 파트 1 | 사람 2 / 파트 2 |
|---|---|---|
| `카세트J카드.html` | **주황** `#C05621` | 파랑 `#2C5282` |
| `매칭스와이프.html` | 파랑 (나) | 주황 (상대) |
| `곡과가사.html` | **파랑** `#2C5282` | 주황 `#C05621` |

제 실수입니다. 페이지를 따로 만들면서 어긋났습니다.
**둘 중 하나로 정해야 합니다.**

제 생각은 **사람 1 = 파랑**입니다. 주황은 대비가 3.98:1 이라 작은 글자에 못 씁니다.
사람 1 이 먼저 나오는 쪽이니 제약이 적은 색을 주는 게 맞습니다.
다만 카세트 J카드에서는 주황이 먼저 나오므로, 보시고 정하세요.

### ② `--ink-3` 로 본문을 쓰고 있습니다

`#A79E93` 은 종이 위에서 **2.30:1** 입니다. 보통 글자 기준(4.5:1)에 한참 못 미칩니다.
지금 `.tiny`(11px)와 `.eyebrow`(11px)에 쓰고 있어서 **읽기 어려운 사람이 있습니다.**

고치는 방법 둘.

- `--ink-3` 을 `#8A8175` 정도로 어둡게 — 종이 위 약 3.4:1. 아직 부족하지만 나아집니다
- 주석 글자만 `--ink-2`(5.14:1)로 올리고, `--ink-3` 은 선·눈금에만 남기기

**두 번째가 낫다고 봅니다.** 색은 그대로 두고 쓰는 자리만 좁히면 분위기가 안 바뀝니다.
