# 이음 — 엔진 명세

Codex 가 읽을 문서는 **이 파일 하나면 됩니다.** 프로토타입 HTML 은 안 읽어도 됩니다.

---

## 0. 규칙

- 엔진 5개는 **화면을 전혀 건드리지 않습니다.** DOM·React·fetch 를 안 씁니다. 값만 주고받습니다.
- 전부 UMD 입니다. `<script src="match.js">` 로도 되고, 나중에 `import` 도 됩니다.
- `<script src>` 로 넣으면 전역에 `Match` `Timbre` `Taste` `Midi` `SongData` 가 생깁니다.
- 음 높이는 **MIDI 번호**입니다. `60` = 가운데 도(C4), `1` 차이 = 반음.
- **엔진 파일은 고치지 마세요.** 화면에 연결만 하면 됩니다.

## 1. 파일

| 파일 | 하는 일 | 의존 |
|---|---|---|
| `match.js` | 음역으로 거르기 · 조옮김 · 파트 배정 | 없음 |
| `timbre.js` | 목소리에서 음색·역할 뽑기 | 없음 |
| `taste.js` | 취향 맞춰보기 · 추천 문구 | 없음 |
| `midi.js` | MIDI 읽기·쓰기 · 가사 시각 | 없음 |
| `song.js` | 곡 데이터 · 화성 붙이기 | 없음 |

서로도 의존하지 않습니다. 필요한 것만 넣어도 됩니다.

## 2. 이어 붙이는 순서

```
음역대측정 화면 ─┐
                 ├─> match.rankCandidates(나, 후보들, 곡, 7)
song.js 곡 ──────┘        │
                          ├─ complete === false  → 후보에서 뺀다 (예/아니오)
                          └─ complete === true   → 아래로
                                 │
    녹음 파형 ──> timbre.features ──> timbre.roles ──> timbre.rolePair ─┐
    앱 활동기록 ─────────────────────> taste.tasteMatch ────────────────┤
                                                                        ├─> 궁합 점수
                                                                        ┘
    곡 ──> midi.write ──> .mid 파일
    곡 ──> midi.syncLyrics ──> 노래방 가사 (글자마다 초)
```

**1단계는 점수가 아니라 예/아니오입니다.** 맡을 파트의 음에 하나라도 못 닿으면 곡이 안 끝나므로 탈락입니다.
**2단계에서만 점수를 매깁니다.**

## 4. match.js — 음역 · 조옮김

### `Match.rankCandidates(me, candidates, song, span)`

가장 많이 쓸 함수입니다. `span` 은 조옮김 허용 반음 수(보통 7). `0` 이면 원조성만 봅니다.

```js
const list = Match.rankCandidates(ME, POOL, song, 7);
const 통과 = list.filter(m => m.complete);
const 탈락 = list.filter(m => !m.complete);
```

**돌아오는 것 (하나당)**

| 키 | 뜻 |
|---|---|
| `complete` | **거름망.** true 면 둘이 이 곡을 끝까지 갈 수 있다 |
| `miss` | 못 닿은 사람들. `[{person, part, detail}]` |
| `semi` | 몇 반음 옮겨야 하는지. `0` 이면 원조성 |
| `rows` | 파트 배정. `[{person, part, fit, detail}]` |
| `reason` | 가장 약한 고리를 한국어 한 줄로 |
| `score` | 음역 점수 0~100. **거름망에는 안 씁니다.** 참고용 |

`rows[i].detail` 안에 `marginLo` `marginHi`(여유 반음, 음수면 못 닿음) `canSing` `tess` 가 있습니다.

### 나머지

```js
Match.noteName(60)                  // 'C4'
Match.transpose(song, 7)            // 곡 전체를 7반음 올린 새 곡
Match.bestKey([a,b], song, 7)       // { semi, song, assign } 또는 null
Match.partFit(person, part)         // { fit, marginLo, marginHi, canSing, ... }
```

**주의** — 그 사람의 음역폭 자체가 파트보다 좁으면 어떤 조성으로도 안 됩니다.
`bestKey` 가 `null` 을 돌려줍니다. 검사로 확인했습니다 (음역 17반음 / 베이스 파트 20반음 → 실패).

## 5. timbre.js — 음색 · 역할

### `Timbre.features(Float32Array, sampleRate)`

파형에서 값을 뽑습니다. 녹음 하나당 한 번만 하고 캐시하세요. 8192점 FFT 라 매번 돌리면 느립니다.

돌아오는 키: `f0` `bark[24]` `harm[8]` `centroid` `rough` `spr` `low` `mid` `even` `density`
`attack`(ms) `release`(ms) `steady`(0~1) `hold`(초)

### `Timbre.roles(features)` → `{ share, top }`

`top` 은 `'메인' | '받침' | '윗화음' | '중간화음'` 중 하나입니다.

### `Timbre.rolePair(rolesA, rolesB)` → `{ a, b, fit, same, label }`

`fit` 0~1. 같은 자리를 둘이 차지하면 낮습니다.

### `Timbre.blend(featA, featB, mode)` → 음색 궁합

`mode` 는 `'blend'`(기본, 닮을수록 높음) 또는 `'contrast'`(갈릴수록 높음).

| 키 | 뜻 |
|---|---|
| `score` | 0~100. **`ok` 가 false 면 `null` 입니다. 반드시 확인하세요** |
| `ok` | 기본음을 잡았는가. 조용하거나 잡음 많은 녹음에서 false |
| `texture` | 결 차이. 줄 세우기는 이 값으로 합니다 |
| `mask` | 가림. **줄 세우기에 쓰지 마세요** (아래 설명) |
| `audible` | `'둘 다 또렷함'` 등. 겹쳐 들었을 때 |
| `label` | `'결이 거의 같음'` 등 |

**`mask` 를 줄 세우기에 쓰면 안 되는 이유** — 음역과 음색을 구분하지 못합니다.
실측: 1옥타브 차이 `0.481` / 같은 높이에 결만 다름 `0.480`. 값이 같습니다.
`texture` 는 음 높이를 지웁니다. 실측: 결은 같고 음높이만 다른 쌍 178개에서 중앙값 `0.030`, 최대 `0.090`.

`Timbre.synth(opt)` 는 마이크 없이 검사할 때 쓰는 합성음입니다. 제품에는 안 씁니다.

## 6. taste.js — 취향

### `Taste.tasteMatch(me, you)`

소리를 안 봅니다. **녹음이 없어도 계산됩니다.**

| 키 | 뜻 |
|---|---|
| `score` | 0~100 |
| `reasons` | **화면에 그대로 띄울 한국어 문구 배열** |
| `songs` | 함께 부를 수 있는 곡 id 배열 |
| `genre` `liked` `wish` | 0~1 |
| `topGenres` | 둘 다 많이 듣는 장르 |

`reasons` 예시 — `['함께 부르기 좋은 곡이 6개 있어요', '자주 부르는 장르가 비슷해요', '저장해 둔 곡이 겹쳐요']`

앞에서 3개만 잘라 쓰면 카드에 맞습니다.

## 7. midi.js — MIDI · 가사

```js
const bytes = Midi.write(song);        // Uint8Array
const back  = Midi.read(bytes);        // { ppq, bpm, title, tracks }
const sync  = Midi.syncLyrics(track, ppq, bpm);
// [{ text:'불 ', tick:0, time:0, end:0.4167, midi:64 }, ...]
```

`syncLyrics` 가 노래방 화면이 쓰는 값입니다. `time` 은 초 단위입니다.

가사는 MIDI 표준 자리(`0xFF 0x05`)에 들어갑니다. 한글은 UTF-8 입니다.
쓰고 다시 읽었을 때 음표 48개 중 어긋남 0개, 글자도 제목도 그대로인 것을 검사로 확인했습니다.

## 8. song.js — 곡

```js
const songs = SongData.songs(480);     // [밤 사이, 마주]
const parts = songs[0].tracks.map(SongData.partRange);   // match.js 에 그대로 넣는 모양
```

곡 하나 모양: `{ title, ppq, bpm, tracks, rows, sections }`
- `tracks[i]` = `{ name, channel, notes:[{midi,tick,dur,vel}], lyrics:[{tick,text}], rows }`
- `rows[i]` = `{ from, to, text, chord }` — 가사 줄바꿈용
- `sections[i]` = `{ name, from, to, who }` — `who` 는 그 구간을 부르는 파트 번호

### `SongData.harmonize(notes, steps, octave)`

가락 한 줄에 화성을 붙입니다. `steps` 는 **반음이 아니라 음계 칸**입니다. `-2` = 3도 아래.
반음으로 내리면 조성을 벗어나는데 이 함수는 안 벗어납니다.

**다른 데서 멜로디를 받아와도 이 함수로 파트를 만들 수 있습니다.**
지금 코드는 가단조 전용입니다. 다른 조성이 필요하면 `AM_PC` 를 바꿔야 합니다.

섞으면 안 됩니다. 아래는 근거의 크기가 다릅니다.

| | 근거 |
|---|---|
| SATB 파트 음역 | **CPDL 악보 92~99곡 실측** |
| 결 차이 10분위 눈금 | **목소리 123개 · 쌍 7,503개 실측** |

| 궁합 0.35/0.25/0.40 | 설계값 |
| `'contrast'` 방향 | **근거 없음.** 기획 전제 |

## 11. 아직 없는 것

- **사람 목소리 데이터 0명.** 모든 설계값은 실제 반응이 쌓이면 다시 맞춰야 합니다.

  나머지 코드는 손댈 게 없습니다.
- 조옮김은 가단조 기준입니다.
